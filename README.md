# mikadodeco.be

Site de la boutique Mikado Deco (mobilier et objets de design, Uccle) : serveur Express en rendu côté serveur sur Vercel, catalogue et paiement Shopify (Storefront API, mode headless).

- Démarrer en local : `npm install`, copier `.env.example` en `.env`, puis `npm run dev` (http://localhost:4000).
- Vérifier : `npm run check` (syntaxe) et `npm test`.
- Publier : une branche et une pull request par changement ; la Preview Vercel se construit à chaque push, `main` part en production.

Règles du dépôt : [`AGENTS.md`](AGENTS.md). Charte visuelle : [`DESIGN.md`](DESIGN.md). Documentation : [`docs/README.md`](docs/README.md).
